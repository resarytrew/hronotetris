# Хроно тетрис

Браузерная аркада для изучения исторических дат. Карточку события нужно направить в одну из пяти полос с правильным годом. Верный ответ очищает блоки, ошибка добавляет их. Есть уровни, серии ответов и бонусы.

Игра: [resarytrew.github.io/hronotetris](https://resarytrew.github.io/hronotetris/).

## Локальный запуск

Требуется Node.js, совместимый с Vite 7 (22.12+ или 24 LTS). Проверено с Node.js 24.16.0.

```powershell
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Открыть http://127.0.0.1:5173/. Для остановки нажать Ctrl+C в терминале сервера.

## Проверка и сборка

```powershell
npx.cmd tsc --noEmit
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 4173
```

Готовый результат — `dist/index.html`. Плагин `vite-plugin-singlefile` встраивает JavaScript, стили, изображение и шрифты в HTML. Папки `node_modules` и `dist` исключены из Git.

## Структура

- `src/App.tsx` — меню, игровое поле, интерфейс и сенсорное управление.
- `src/game/engine.ts` — состояние игры, карточки, очки, уровни и бонусы.
- `src/game/useGame.ts` — цикл requestAnimationFrame, клавиатура и автопауза при скрытии вкладки.
- `src/game/audio.ts` — звуковые эффекты через Web Audio API.
- `src/data/events.json` — 256 событий из пользовательского файла «Все даты для ОГЭ до 1801 г.», с исходными названиями и полными датами.
- `src/data/events.ts` — загрузка базы и сдвиг дат для вариантов ответа; интервалы и перечисления лет сохраняют свой формат.
- `src/index.css` — оформление и анимации.

Управление: ←/→ — выбор полосы, ↓ — ускорение, пробел/↑ — сброс, 1/2/3 — бонусы, P/Esc — пауза. На сенсорном экране: касание полосы выбирает её, повторное касание сбрасывает карточку; также есть кнопки под полем.

## Хранение данных и статическое размещение

Приложение полностью работает в браузере. API, серверная часть, аккаунты и общий рейтинг отсутствуют. Личный рекорд хранится в localStorage под ключом `chrono-blocks-best` и записывается после окончания игры. Текущая партия после перезагрузки не восстанавливается. Рекорд относится к браузеру и origin сайта; между localhost и опубликованным сайтом он автоматически не переносится.

Для размещения на статическом хостинге предназначен результат сборки из `dist`, а не исходные TSX-файлы. У приложения нет клиентских маршрутов и серверных зависимостей. Сборка использует относительные пути и работает в подпапке `/hronotetris/`.

GitHub Pages публикует приложение через `.github/workflows/deploy-pages.yml`: при push в `master` устанавливаются зависимости, проверяется TypeScript, собирается приложение и загружается содержимое `dist`. Публикацию также можно запустить вручную в разделе Actions → Deploy GitHub Pages → Run workflow. Источник публикации в Settings → Pages — GitHub Actions.

В `vite.config.ts` явно задана пустая конфигурация PostCSS: Tailwind подключён отдельным Vite-плагином, поэтому конфигурации из родительских папок не должны влиять на проект.

## Наблюдения для дальнейшей работы

- Интерфейс масштабирует фиксированную сцену 640×1060 целиком; на узких экранах текст и кнопки уменьшаются вместе с ней.
- Учебная база пока представляет собой единый список без выбора эпох, тем или сложности.
- Карточки увеличиваются для длинных названий событий; диапазоны и перечисления лет показаны на плитках в две строки.
- Исторические формулировки и даты требуют отдельной содержательной проверки перед учебным использованием; первоначальное изучение касалось кода и запуска.
